## Расшифровка варианта

| Элемент                | Код      | Смысл                                                                          |
| ---------------------- | -------- | ------------------------------------------------------------------------------ |
| Источники              | `ИБ` + `ИЗ2` | Бесконечные, интервалы между заявками — равномерное распределение              |
| Приборы                | `ПЗ1`      | Время обслуживания - экспоненциальное                                          |
| Постановка в буфер     | `Д1ОЗ3`    | На первое свободное место (без сдвига очереди)                                 |
| Отказ                  | `Д1ОО5`    | Если буфер полон - отказывают именно вновь пришедшей заявке (буфер не трогаем) |
| Выбор прибора          | `Д2П1`     | Приоритет по номеру прибора (всегда сначала пытаемся занять "прибор №1")       |
| Выбор из буфера        | `Д2Б4`     | Приоритет по номеру источника, по одной заявке                                 |
| Отображение (автомат)  | `ОР1`      | Итоговая таблица характеристик                                                 |
| Отображение (пошагово) | `ОД3`      | Временные диаграммы                                                            |
